## 开发中发现并处理
     
1. 沙箱进程和编辑助手初始化异常：通过明确授权的沙箱外操作完成工程文件/构建，没有改固件或设备。
2. 机器缺.NET SDK：放置工程内SDK，未将UI改为与规格不同的技术栈。
3. 模拟实时模型在第一条心跳到达前会提前锁故障：改为等到配置超时后触发，回归验证。
4. 初版界面浅色ComboBox文字对比度不足：设置专用内容模板后重新构建。
5. 原始驱动估算功率与独立测扭报告需区分：结果增加TorqueSource，外部健康数据优先，无外部数据不生成最终效率。
     
原始需求Word保持不变。该记录描述软件检查，不是硬件安全或Design Freeze放行。

6. 停转附近若按普通斜坡回零会留下短时驱动力：改为最小加载转速以下立即清零目标；增加被动转矩/转速符号相反校验，两项新增回归通过。
