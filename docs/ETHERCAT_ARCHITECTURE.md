# Windows 直连 SV660N 负载台架设计

## 确定的架构

Windows WPF（UI / 测试流程 / 记录）→ PC EtherCAT Master → 专用有线网卡 → EtherCAT CoE / CiA402 → SV660N → MS1H4 750 W → 摩擦轮 → 被测大电机。

不使用 PLC。InoDriverShop 经 COM3 仅作为已有调试通道；新工具的 EtherCAT 主站不依赖其 API。COM3 可驱动电机说明串口调试链路有效，不能据此判断 EtherCAT 链路有效。协议切换、启动参数、控制权选择必须按 SV660N 实际固件手册确认；运行负载测试时不得有两个控制源同时下发运动指令。

## 软件分工与边界

- WPF：操作、配方、限值编辑、数据显示和日志；不承担周期 PDO 调度。
- 主站进程：独占所选有线网卡，EtherCAT 从站识别、CoE 配置与诊断、PDO 周期收发、CiA402 状态管理、加载斜坡、工作计数器/周期超时检查。
- 进程通信：版本化命令/状态，递增序号、单调时钟时间戳、命令有效期。UI 断开或命令过期不保持最后负载；主站进入停止处理。数据记录慢不得阻塞 PDO 循环。
- 驱动器与台架：通信故障反应、独立停机链、回生能量处置、机械防护。掉线时无法依靠继续发 PDO 停机；必须验证驱动器超时后的实际行为和 DUT 协同停机。
- 扭矩传感器：DYN-200 另设 RS-485 采集任务，记录量程、时间戳、有效性和安装轴位置。它不能与 COM3 驱动器调试链路混为一条连接。

当前已实现的主站入口为 PySOEM/PRE-OP 调试；后续周期控制主站与 WPF 分开实现。Windows/Python/USB 网卡组合必须先测周期抖动、WKC 丢失与驱动超时，不能承诺 1 ms 确定性。若达不到目标，替换为适合 Windows 的实时主站运行环境，仍保留上位机、协议与无 PLC 架构。不得通过降低故障检测要求来掩盖周期不稳定。

## EtherCAT 调试和控制阶段

1. 枚举并明确选择专用网卡。不得自动扫描 Wi-Fi、蓝牙、办公网络或另一个主站正在使用的总线。
2. PRE-OP 初始化总线，读取 EEPROM 标识和 CoE 1018 对象。保存 Vendor/Product/Revision/Serial、ESI 文件哈希与软件版本。
3. 读取 1C12/1C13 以及引用的 PDO 映射，核对对象存在性、数据宽度、有符号性、大小端、单位、支持模式。不猜测 Rx/TxPDO 字节偏移。
4. 对照固件资料核对目标模式、同步方式和允许周期；设定通信看门狗与驱动器通信故障反应。配置写入必须回读确认，失败即终止。
5. 建立零指令 PDO，确认 SAFE-OP / OP 和期望 WKC，再验证模式显示及 CiA402 状态。进入 EtherCAT OP 不代表 CiA402 已使能。
6. 经过联锁和方向确认后从零转矩使能；恒转矩、恒功率、转速-转矩曲线使用统一限幅与斜坡。故障复位不自动恢复负载。
7. 停止时降低负载并确认反馈，再禁能；超时按实际驱动器与台架验证过的故障方案处理，不把“发送了零值”等同于已经停机。

核心对象计划：6040/6041（控制/状态）、6060/6061（设定/实际模式）、6071（目标转矩）、6077（反馈转矩）、606C（速度）、603F（错误）、6502（支持模式）。CST 为候选模式；是否可用及其对象单位由型号固件资料和实读结果确认。

## 摩擦轮力矩换算

设伺服轮有效半径 Rs，被测轮接触半径 Rd，暂不含减速机构：

- 无打滑时接触切向速度幅值相等：|ωs| Rs = |ωd| Rd。
- 理想切向力幅值 F = |Ts| / Rs，被测轴等效阻力矩 |Td| = F Rd = |Ts| Rd / Rs。
- 接触方向决定符号，不能把伺服转向直接当作被测轴转向。必须现场确认轴正方向和接触几何。
- 滑移可由两侧独立转速估算：||ωs|Rs − |ωd|Rd| / max(|ωs|Rs, |ωd|Rd, v_min)。低速区不作有效滑移判定。
- 若只有伺服侧速度，无法独立确认摩擦轮滑移。DYN-200 的速度若来自伺服同一轴，也不能补足被测侧速度。
- 由伺服估算转矩换算的 Td 仅为理想等效估计；轮面变形、轴承损耗、滑移影响实际值。性能验收优先使用安装在已知轴位的独立扭矩传感器测量。
- 750 W 为用户提供的电机额定功率，不等同于台架可连续吸收 750 W。连续阻尼还受电机/驱动器额定转矩转速、回生电阻或回馈能力、摩擦轮附着与温升限制。

配置保留但不猜测：伺服完整型号、额定转矩/转速、Rs/Rd、传动比、传感器安装轴、被测侧转速来源、接触预紧力、连续回生能力。缺少这些数据时不生成真实 Nm 负载指令。

## 记录与验收

每次测试保留配置/ESI 哈希、驱动身份、PDO 布局、目标/反馈原始量与工程量、两侧转速、独立扭矩、电源功率、温度、周期统计、WKC 和报警。时间戳来自单调时钟并关联 UTC；不同设备数据注明采样延迟，不能把串口与 EtherCAT 异步值假设为同时采集。

离线验收：CiA402 解码、SDO 宽度/符号、PDO 映射解析、失败清理、禁止未选网卡扫描。
现场验收：从站识别 → CoE 读取 → 单位/方向 → 零转矩使能 → 低负载 → 断线/掉站/主机冻结 → 摩擦轮打滑与温升 → 持续负载及回生能力。进入下一阶段以实际结果为依据。
