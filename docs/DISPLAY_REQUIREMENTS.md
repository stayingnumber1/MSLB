# 三模块实时数据显示需求

## 总体原则

- 首页按数据来源划分为“负载伺服系统、DYN-200 扭矩传感器、被测电机（DUT）”三个独立区域，避免同名参数混淆。
- 每个量固定显示名称、数值和工程单位；未建立采集通道时显示“未接入”，不得用 `0` 冒充有效测量值。
- 原始量和计算量在数据模型中分开。功率统一使用 W，转速使用 rpm，扭矩使用 N·m，效率使用 %。
- 机械功率按 `P = |T × n × π / 30|` 计算。DUT 输入功率按 `Pdc = |Udc × Idc|` 计算；DUT 效率为扭矩传感器机械功率除以 DUT 输入功率。
- 负载伺服可能工作在回生象限。在母线功率方向和驱动器效率数据完成核验前，伺服效率只显示驱动器/采集链提供的值，不用 DUT 公式推算。

## 模块字段

| 模块 | 显示字段 |
|---|---|
| 负载伺服系统 | 转速、母线电压、相电流、扭矩、伺服吸收功率、伺服回馈功率、负载率、驱动模块温度 |
| DYN-200 扭矩传感器 | 通信状态、扭矩、转速、机械功率 |
| 被测电机（DUT） | 母线电压、母线电流、相电流、占空比、电机温度、效率、转速 |

## 数据有效性

- DYN-200 数据仅在串口帧通过 CRC 且未超时时有效。
- 伺服扭矩在 N·m 标定系数缺失时显示“未接入”。
- 当前 SV635/SV660 监控对象提供的是驱动模块温度，不得标成电机绕组温度。母线电流、PWM 占空比及电机绕组温度在取得可靠采集对象前保持“未接入”。
- 伺服吸收功率来自 DYN-200 轴端扭矩与转速；伺服回馈功率必须来自带方向的直流母线功率测量，未取得母线电流前显示“未接入”。
- 效率仅在输入功率大于零且扭矩传感器功率有效时计算；分母无效时显示“未接入”。
- CSV 同时保存三个模块的原始量与计算量，空字段代表该采集通道尚未接入或当帧无效。
